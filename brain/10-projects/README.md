# 10 Projects

Work with a clear goal and an end date. One folder per project, named with a short kebab-case slug, e.g. `practice-area-pages/`.

Each project folder has an `index.md` made from `_templates/project.md` that states the goal, the deadline, the status, and links to its notes. When a project ships, set its status to `done` and move the whole folder to `40-archive/`.
