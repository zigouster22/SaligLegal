# Salig Legal second brain

This folder is the project's knowledge workspace: research, drafts, decisions and reference material for the Salig Legal website. It is organised with the PARA method, numbered so folders sort in workflow order.

| Folder | What goes here | Leaves when |
|---|---|---|
| `00-inbox/` | Anything captured but not yet filed: raw notes, links, client questions, ideas | Triaged (at least weekly) |
| `10-projects/` | Work with a goal and an end date, e.g. "Launch practice-area pages" | The project ships, then it moves to `40-archive/` |
| `20-areas/` | Ongoing responsibilities with no end date, e.g. brand voice, SEO, compliance | It stops being a responsibility |
| `30-resources/` | Reference material by topic: legal sources, practice areas, competitors, style | It goes stale, then it moves to `40-archive/` |
| `40-archive/` | Finished projects and retired material, kept for history | Never deleted without the owner's say-so |
| `_templates/` | Note templates every note starts from | n/a |

See [`../CLAUDE.md`](../CLAUDE.md) for the rules Claude follows when filing, linking and maintaining notes, and [`../.claude/agents/`](../.claude/agents/) for the four specialist agents.
