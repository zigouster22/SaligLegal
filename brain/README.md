# Salig Legal second brain

This folder is our shared second brain: the single home for research, requirements, drafts, decisions and reference material for the Salig Legal project. There is no other knowledge folder.

**Agents: read this file and the relevant notes before starting any task** (see CLAUDE.md section 0a). Aldred is the Product Owner, Product Engineer and Quality Engineer, with final decision authority.

It is organised with the PARA method, numbered so folders sort in workflow order.

| Folder | What goes here | Leaves when |
|---|---|---|
| `00-inbox/` | Anything captured but not yet filed: raw notes, links, client questions, ideas | Triaged (at least weekly) |
| `10-projects/` | Work with a goal and an end date, e.g. "Launch practice-area pages" | The project ships, then it moves to `40-archive/` |
| `20-areas/` | Ongoing responsibilities with no end date, e.g. brand voice, SEO, compliance, and `decisions/` (`proposed/` and `approved/`) | It stops being a responsibility |
| `30-resources/` | Reference material by topic: legal sources, practice areas, competitors, style | It goes stale, then it moves to `40-archive/` |
| `40-archive/` | Finished projects and retired material, kept for history | Never deleted without the owner's say-so |
| `_templates/` | Note templates every note starts from | n/a |

See [`../CLAUDE.md`](../CLAUDE.md) for the rules Claude follows when filing, linking and maintaining notes, and [`../.claude/agents/`](../.claude/agents/) for the specialist agents.

## Decisions

- `20-areas/decisions/proposed/`: decisions awaiting Aldred. Not binding.
- `20-areas/decisions/approved/`: decisions Aldred has approved. Binding on all work.
