# 00 Inbox

The capture point. Drop anything here without worrying about where it belongs: a note, a link, a question from a client, a half-formed page idea.

- Name files `YYYY-MM-DD-short-slug.md`.
- Nothing lives here for long. The `knowledge-librarian` agent triages the inbox into projects, areas, resources or the archive.
- Never put client-confidential details here (or anywhere in this repo). See CLAUDE.md, "Confidentiality".
