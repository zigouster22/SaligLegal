# Decisions

Every significant decision about scope, design, technology, content policy or process is one note, made from `brain/_templates/decision.md`.

| Folder | Meaning | Who puts notes here |
|---|---|---|
| `proposed/` | Awaiting Aldred's decision. Not binding. | Any agent or Claude |
| `approved/` | Approved by Aldred. Binding on all work. | Moved here only on Aldred's explicit approval |

Rejected or superseded decisions move to `brain/40-archive/20-areas/decisions/`. File names: `YYYY-MM-DD-short-slug.md`.
